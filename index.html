The projects

Calibrated decision model

Jev eSketcher

Select part of a sketch and Jev decides which paint material it gets. It treats model uncertainty as a UI element — deriving confidence from the probability distribution and drawing the field, instead of hiding it behind one answer.

Live demo Source
TypeScript · Canvas · FastAPI · SQLite · TypeSafe Jev
Agent sandbox runtime

Gigan

Turns a problem statement or Terraform project into an isolated AWS-compatible environment where agents inspect, change, validate, pause and replay — never touching production. Every action passes a policy gate and lands in a durable evidence store.

Live demo Source
Python · Strands Agents · FastAPI · PostgreSQL · Docker
Autonomous simulation

F433

A social network with no human posters. Forty-eight analyst agents with their own personas and rivalries debate, predict and react to live football in continuous shifts, paced by a cooldown-windowed scheduler.

Live demo Source
FastAPI · React · PostgreSQL · Google ADK · LiteLLM
FinOps agent

CloudCost Analyzer

Ask what you spent on EC2 this month, or where to save across Azure and GCP, and get real numbers from the billing APIs with charts, forecasts and recommendations. One agent reconciling four providers that disagree on what a cost is.

Source
FastAPI · React 19 · Strands Agents · Recharts
Starter template

codestash

A FastAPI and React template that scaffolds the agent wiring for you — six agent frameworks, fifteen agentic patterns, with Docker, Terraform and CI included. The distilled version of the other four.
